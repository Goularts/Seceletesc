# Revisão da F4.5 (decisões da F4, portão de mudanças com Ruflo, demonstração local): disposição dos achados

Revisores: `guardiao-regras` (veredito **APROVADO** com ressalvas) e `seguranca` (1 alta, já corrigida antes do fim da revisão; nenhuma crítica), mais uma rodada de mutação. Bugs desta rodada registrados com o próprio portão (`registrar.cjs`): REG-015 a REG-018.

**Disposições possíveis:** corrigido (com evidência), aceito como risco (com motivo), adiado (com fase), rejeitado (com motivo), pendente de decisão do Victor.

| # | Achado | Disposição |

| S1 | Injeção de comando pelo prompt (o npx no Windows passa por shell; `%VAR%` expande antes das aspas) | **Corrigido em duas camadas:** Ruflo instalado no projeto (`package-lock.json`, `npm ci --ignore-scripts`) e chamado pelo Node **sem shell**; o fallback pelo npx só recebe texto filtrado por `seguro()`.
